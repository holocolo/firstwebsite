第一次文生图：文字生成图片

接上 OpenRouter 的 openai/gpt-5.4-image-2 做了一屏「打字出图」， 用 Google 那种极简白底风格做的界面。中间踩了个坑：chat/completions 在本机所在地区被区域限制挡掉（403），换成专用的 /api/v1/images 才通 —— 也算学会了「一个模型可能有多个可用端点， 不通就换一条路试试」。

2026 · 09

第一个实用工具：一键去除图片背景

调 Replicate 上的 lucataco/remove-bg 模型做出抠图工具： 拖拽上传、原图与结果对比、一键下载透明 PNG。因为浏览器端存不住密钥， 顺手写了个 Python 小服务把 API Key 藏在环境变量里 —— 第一次搞明白 前端该做什么、后端该做什么。

2026 · 09

第一次 API 调用

在个人主页右上角接入了 Open-Meteo 的天气接口，用 fetch 请求 JSON 数据、 再把实时气温和天气状况渲染到页面上 —— 第一次让自己的网页能"拿到外面的数据"， 也搞懂了无需 API Key 的公开接口怎么用。

2026 · 09

第一个个人网页：我的个人主页

用 HTML + CSS 独立完成了个人主页，包含「关于我」和「学习记录」两屏， 适配了手机和电脑，也学会了怎么用变量统一管理页面颜色。
